# GitHub Profile Finder

A web application that allows users to search for GitHub profiles using their GitHub username.

## Features
- Search GitHub users by username
- Display profile picture
- Show followers and following
- Display public repositories
- View GitHub profile

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub API

## Concepts Learned
- Fetch API
- JSON
- Async/Await
- DOM Manipulation
- Error Handling

## How to Use
1. Enter a GitHub username.
2. Click the Search button.
3. View the user's GitHub profile details.
